# 初始发布真实浏览器人工验收清单

`npm run gate`
的三引擎自动化（Chromium 完整读者主路径、Firefox 与 WebKit 核心 smoke）证明的是 Playwright 维护的引擎构建行为，不能冒充真实品牌浏览器的端到端证据（ADR
0239）。本清单用于首次局域网发布、浏览器基线变化或主要依赖升级时，在真实稳定版 Chrome、Edge 与 Safari 上完成一次人工阅读路径验收。

自动化基线：构建目标 `chrome111 / edge111 / firefox114 / safari16.4`，测试工具
`@playwright/test 1.62.1`（Chromium 151.0.7922.34、Firefox 153.0、WebKit 26.5）。

## 执行边界

- 只在获准局域网入口（HTTP，非 HTTPS）执行；不得用本清单结论替代 `npm run gate`。
- 每台设备填写实际浏览器版本号与执行日期；未执行的行保持「未验证」，不得补填。
- 任一失败项都必须记录复现步骤、截图与浏览器版本，并回到代码 Issue 修复。

## 验收项

### 1. 七类读者页面可达（Chrome / Edge / Safari 各一遍）

- [ ] 首页：默认进入软件工程领域，URL 写入稳定领域路径。
- [ ] 时间线：默认每日视图，可切到完整自然周的每周视图。
- [ ] 主题总览：主题为主层级、标签索引为辅助层级。
- [ ] 主题详情：主题身份 → 已确认判断 → 相关洞察的纵向顺序。
- [ ] 标签详情：定义、别名、适用领域与相关主题矩阵。
- [ ] 洞察详情：事实栏、核心判断、技术机制、重要性与适用范围。
- [ ] 来源归档：正文、图片与归档证据信息。

### 2. 响应式与布局（手机宽度 < 720、平板 720–1023、桌面 ≥ 1024）

- [ ] 手机：单列结构，根页面无水平滚动。
- [ ] 平板：中等屏幕语义重排，不是缩小版桌面。
- [ ] 桌面：内容最大宽度约 1120px，正文行长约 72ch，洞察事实栏约 280px。
- [ ] 图片与图示缩放到内容区，无破版。

### 3. 交互等价性

- [ ] 鼠标、键盘（Tab/Enter/Escape）与触摸均可打开、关闭首页来源覆盖信息。
- [ ] 关闭来源覆盖后焦点回到触发按钮。
- [ ] 时间线「查看更早洞察」加载更多后，返回可恢复尺度与已加载内容。
- [ ] 断网时点击加载更多显示错误与「重试」，原内容与 URL 不变；恢复后重试成功。
- [ ] 直接打开非法游标 URL 显示明确错误与返回链接，不静默回退。

### 4. 安全与缓存观察（开发者工具网络面板）

- [ ] 所有响应带 CSP `default-src 'self'` 等安全头，无第三方运行时请求。
- [ ] 无 Service Worker 注册。
- [ ] HTTP 响应不含 `Strict-Transport-Security` 头。
- [ ] 刷新页面时 HTML 走重验证（304 或 200），内容寻址资源命中磁盘缓存。
